# Security, auth and tenancy

Each "Never break" rule from `AGENTS.md`, and where it is enforced. Last full audit: [SECURITY_AUDIT.md](../SECURITY_AUDIT.md) (2026-11-02; open findings and owner actions are listed there).

- **Secrets:** only in Vercel env; never in code, logs, error messages or client bundles. Check presence, never print values. `gitleaks` runs in CI over full history; no PII in logs. Cron secret compare is constant-time and fails closed.
- **Tenancy:** every row has `organization_id`; procedures get `ctx.principal.organizationId` from middleware and repositories take `orgId` as a required argument, joins included. `packages/core/src/router/tenant-isolation.test.ts` replays organization A's ids as organization B against **every** procedure and fails with "every procedure is covered by a case" when a new procedure has none — add the case in the same PR. Any foreign key a caller supplies (contact, bank account, document, template, rule) is re-checked inside the organization.
- **Public endpoints** (`/f/:token`, `/f/:token/pdf`, ISDOC, ARES/ČNB lookup proxies): the public token is unguessable (24 random bytes, base64url), exists only on issued documents, and is revocable (`documents.rotateLink`; the old token dies immediately). The public payload is an explicit allow-list asserted key by key (`public-security.test.ts`): no private note, internal ids, customer e-mail or phone. Pages are `noindex`, `no-store`, `Referrer-Policy: no-referrer`. Lookup proxies are cached and rate-limited per organization, hosts are constants, IČO is checksum-validated before any fetch.
- **Auth:** Better Auth — session cookie (web), API keys `fk_…` (REST/CLI, one organization each, hashed at rest, per-key rate limit), OAuth 2.1 + CIMD for MCP clients (API keys also accepted as bearer). An invalid key never falls back to the session. Auth endpoints are rate-limited (5 wrong sign-ins from one IP, then 429).
- **CSRF:** cookie-authenticated mutations (server functions, `/api/rpc`, `/api/v1`) go through an origin check middleware in `apps/web/src/start.ts`; API-key requests are exempt. Adding a TanStack Start `start.ts` replaces the framework's own protection — keep the middleware.
- **Headers** (`apps/web/src/server/security-headers.ts`, unit-tested): per-request nonce CSP with `strict-dynamic`, `frame-ancestors 'none'`, HSTS (no preload until the domain is final), `X-Frame-Options: DENY`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy`, COOP. `/docs/api` serves its own CSP (SRI-pinned Scalar bundle). Don't loosen a header without a decision entry.
- **Assistant:** system prompt forbids acting on instructions found in data (invoice texts, contact notes); destructive tools always need approval in the UI; it executes with the signed-in user's context, so tenant isolation holds by construction. Spend caps: [0009](../decisions/0009-assistant-vercel-ai-gateway-hard-spend-caps.md).
- **CI:** CodeQL (`security-extended`), gitleaks, OSV-Scanner (`osv-scanner.toml` holds expiring accepted advisories), dependency review, Dependabot. Vulnerabilities are reported privately — see `SECURITY.md`.
